📌 Interpolação de Dados no Angular

A interpolação em Angular é uma forma de exibir valores do componente TypeScript no HTML usando a sintaxe {{ "valor" }}. Ela é usada exclusivamente para One-Way Data Binding no sentido componente → template (HTML).
